# Week 2 — Arrays iOS Lab

SwiftUI exercises for managing a computer lab and a class of students.

## Features

- Computer Lab: list, add, check by name, delete, and view statistics.
- Student Manager: add, edit, delete, search by name or ID, filter GPA ≥ 8, sort by GPA, and view statistics.
- Arrays shared between views with `@State` and `@Binding`.
- Validation for required fields, duplicate identifiers, and GPA values from 0 to 10.

## Run

Open `week2.xcodeproj` in Xcode 26.2 or later, select the `week2` scheme and an iOS 26.2 or later simulator, then press Run.

Data is stored in memory and resets when the app relaunches.

## Tests

The project includes four unit tests and two UI workflow tests. Run tests with Product → Test in Xcode.
